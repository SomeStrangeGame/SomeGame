# Project agent instructions

Канонический project root — Git-корень `SomeGame` (на этой машине
`/Users/iantonishin/Fork/SomeGame`). Родительская папка `Fork` является только
контейнером: не открывайте её как workspace, не создавайте там coordination
state и выполняйте проектные команды из `SomeGame`.

Перед любой работой полностью прочитайте общий индекс документации и выберите
в нём обязательные руководства для своего типа задачи:

`Docs/AI/README.md`

Краткий устойчивый контекст проекта хранится в `Docs/AI/memory/`. Обязательный
минимум и правила адресного чтения определяет индекс; memory bank не заменяет
тематические руководства, runtime handoff и проверку текущих файлов.

Перед инспекцией, изменением файлов, запуском Unity, валидации или сборки
полностью прочитайте и соблюдайте:

`Docs/AI/rules/ParallelRefactoringCoordination.md`

Это компактное обязательное ядро. Указанный в нём адресный протокол полностью
читается только для применимой операции: изменение scope, Unity/FIFO,
интеграция общего контракта или обновление memory bank.

Мелкая непересекающаяся правка существующей документации может использовать
docs-only fast path из coordination core без agent/request/write-lock и
handoff, только если выполнены все перечисленные там ограничения.

Операционная очередь и журнал передачи находятся в:

`Docs/AI/CoordinationRuntime/`

Если среда не поддерживает автоматический импорт инструкций, откройте эти
файлы явно до начала работы.

Тематические требования, включая правила персонажей, выбираются через общий
индекс. Указанный там набор для текущей задачи обязателен целиком.
