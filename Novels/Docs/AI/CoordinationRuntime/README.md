# Coordination runtime

Операционное состояние координации чатов для репозитория `SomeGame`.

- `requests/` — FIFO-заявки на изменение проекта или тяжёлую операцию.
- `active/write-lock/` — атомарная блокировка текущего владельца.
- `agents/` — область и состояние задач отдельных чатов.
- `HANDOFF.md` — журнал передачи результатов.

Полный протокол находится в
`../ParallelRefactoringCoordination.md`. Пустые `.gitkeep` сохраняют структуру
каталогов. Не удаляйте чужие runtime-записи и не считайте Markdown-статус
заменой атомарному `write-lock`.
