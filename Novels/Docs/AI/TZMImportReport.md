# Импорт полной истории TZM

Дата импорта: 2026-08-20.

## Результат

- Полная история импортирована как отдельный content id `TZM`.
- Тестовая история `TZM_1` сохранена без изменений и продолжает быть отдельной записью каталога.
- Добавлены семь эпизодов: `s01e01`–`s01e07`.
- Исходные Ink-файлы перенесены без редактирования текста и команд сценаристов.
- Персонажи, общие presentation-prefab и настройки размещены внутри собственного контента `TZM`.
- Для одежды главной героини временно импортирован первый цвет; для волос — вариант «Блонд», согласно принятому временному правилу.
- Добавлены отдельные bundle-границы `novels_content_tzm` и `novels_episode_tzm_s01eXX`.
- История добавлена в `NovelCatalog` под названием «Тайна Затерянного Мира — полная история».

## Совместимость ресурсов

В исходной поставке Ink обращается к ресурсам русскими именами, а изображения первой серии названы техническими английскими именами. Импортёр создаёт внутри `TZM` отдельные русскоязычные копии-алиасы. Runtime-локализация для этого не возвращалась, а `TZM_1` не используется как источник контента новой истории.

В поставке визуальные ресурсы находятся в английских папках `Locations` и `Cut-Scenes`, тогда как параллельные русские папки пусты. После дополнительного сопоставления английских технических имён с командами Ink количество нерезолвящихся ссылок уменьшилось с 93 до 55. Оставшиеся ссылки относятся к действительно отсутствующим либо неоднозначным ресурсам: для неоднозначных вариантов импортёр намеренно не выбирает случайную картинку. В `s01e07` находится заглушка «В разработке». В первой серии отсутствует статичный ресурс «Мотоцикл остановка», хотя связанный видеоконтент также требует отдельной проверки в Unity.

Для недостающих фонов действует текущее проектное правило: валидатор сообщает предупреждение, а игра использует чёрный фон. Это позволяет собрать и прогнать историю до получения оставшегося контента.

Аудиофайлов в новой поставке нет. Импортированы 14 совместимых файлов из ранее предоставленного набора `TZM_1`; остальные обращения должны остаться предупреждениями валидатора до получения аудио.

## Повторный импорт

Основной импорт:

```bash
ruby Tools/import-tzm.rb /Users/iantonishin/Documents/tzm
```

Повторное обновление доступных совместимых ресурсов без пересоздания всей истории:

```bash
ruby Tools/import-tzm-compatible-resources.rb /Users/iantonishin/Documents/tzm
```

## Следующая проверка в Unity

1. Дождаться штатного импорта `.meta` для новых изображений и медиа.
2. Запустить `Novels/Content/Validate Content`.
3. Разобрать ошибки персонажей и команд отдельно от ожидаемых предупреждений о недостающих фоне и аудио.
4. Только после успешной структурной валидации собирать bundles.

Unity и сборка bundles во время автоматического импорта намеренно не запускались, чтобы не повторить чрезмерное потребление памяти при массовом реимпорте.
