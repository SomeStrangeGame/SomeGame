# Один WebGL-плеер для каталога

`/player/index.html?story=<id>&version=<release>` открывает историю напрямую.
Источник разрешённых историй — `/player/config.json`; query не может задать
произвольный URL манифеста или сборки. По умолчанию `player: null` и пустой
`stories`: существующий каталог/предпросмотр/приложение работают как раньше,
ссылки «Читать в браузере» скрыты. Production-конфигурация ещё не включена.

При подготовке отдельного релиза `player` должен содержать `loaderUrl`,
`dataUrl`, `frameworkUrl`, `codeUrl`, `streamingAssetsUrl` с точными путями
экспорта Unity под `/player/builds/<immutable-build-id>/`. Не переименовывать
хешированные файлы и не направлять WebGL на Android bundles. Каждая запись
`stories[id]` содержит `title`, `version` и `manifestUrl`, строго равный
`/content/stories/<id>/<version>/webgl/release.json`. Сначала размещаются все
ресурсы, затем переключается config; конфигурация запрашивается без кеша.
Публикация требует отдельной проверки заголовков сжатия/MIME/CORS и разрешения.

Плеер вызывает `Launch`, `NextEpisode`, `ReturnToSite` на `WebStoryPlayer` и
обрабатывает `somegame:web-player-event`. Выход производится только после
`return_to_site`; повтор после ошибки сейва не перезагружает страницу и даёт
Unity повторить запись сохранённого в памяти snapshot. Данные пользователя
не очищаются. Сейвы локальные, IndexedDB; межустройственной синхронизации нет.
Предупреждение при закрытии вкладки консервативно включено на время сессии;
браузер не гарантирует его показ и завершение незаконченной записи.

Локальная проверка из основного SomeGame: запустить
`python3 Projects/web-story-player/Tools/serve-smoke.py`, затем открыть
`http://127.0.0.1:8767/player/index.html?story=chernaya-melnitsa&version=smoke-boundary-20260912&smoke=1`.
Сервер подставляет конфигурацию существующей локальной сборки и
добавляет только локальные кнопки отказа/возобновления IndexedDB, отсутствующие
в production-файлах. Корень этого тестового сервера — старый debug harness,
а не каталог; переход назад проверяет URL `/`, не вёрстку каталога.

Проверено 2026-09-12 во встроенном браузере: реальное чтение второго эпизода,
отказ записи → сообщение → повтор без reload → восстановление последнего
действия, выход на `/`, desktop 1280×720, portrait 390×844, landscape 844×390.
В коротком landscape история прокручивается вертикально. Development Console
Unity показывает ожидаемую искусственную ошибку; это development build.

Для полного локального каталога при работающем smoke-сервере запустить из
`Website` команду `SOMEGAME_WEBGL_SMOKE=1 npm run dev -- --host 127.0.0.1`.
Открыть Local URL, напечатанный сервером. Vite проксирует WebGL в localhost:8767,
а остальные `/content/` — read-only на публичный сайт; это только dev-настройка.
Каталог использует same-origin `/content`, поскольку публичный manifest не
отдаёт CORS-разрешения localhost. На production content должен быть на том же
origin, что и сайт. Не публиковать локальный smoke-config или debug controls.

изменения каталога, APK, root HTML или существующих версий историй. WASM 7,67 МБ;
плеер суммарно 11,55 МБ. Нативные gzip/MIME/immutable проверены на сервере;
тестовая страница no-cache/noindex. Запуск, два действия, возврат на сайт и
восстановление той же реплики проверены во встроенном браузере; error/warn пусты.
Тест доступен по прямой ссылке без серверной авторизации, noindex не является
защитой доступа. Полное прохождение именно Release-сборки и реальные мобильные
устройства остаются отдельными проверками. Текущий /player/config.json в исходниках
по-прежнему выключен. Тест не использует и не сбрасывает прежние локальные сейвы.
