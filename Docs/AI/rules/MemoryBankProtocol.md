# Memory bank protocol

Каноническая долговременная память находится в `Docs/AI/memory/`.

Перед любой задачей читаются `memory/Project.md` и `memory/Architecture.md`.
Адресно: decisions — для контрактов, workflows — для validation/Unity/build,
known issues — для диагностики, glossary — при неоднозначном термине.

Memory bank не заменяет текущий handoff, FIFO/write-lock, Git, первичные
rules/guides, код, конфигурацию и свежие логи. В него не попадают прогресс,
владение, dirty paths, PID, разовые результаты, полные логи или предположения.

Хранятся только устойчивые факты, действующие решения, короткие маршруты и
подтверждённые известные проблемы. Один факт имеет одно каноническое место;
memory содержит резюме и ссылку, а не копию первичного документа.

При изменении контракта в одном write-lock обновляются первичный документ,
memory-запись и маршрутизатор. Каждый memory-файл остаётся короче 200 строк,
`Project.md + Architecture.md` — короче 400. История уходит в archive, runtime
state — в handoff, автоматически извлекаемые данные не дублируются вручную.

Индекс и назначение файлов: [memory/README.md](../memory/README.md).
