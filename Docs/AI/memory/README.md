# SomeGame memory bank

Memory bank — компактная долговременная память репозитория. Он ускоряет вход в
контекст, но не является журналом работы и не заменяет исходный код или
подробные протоколы.

## Обязательное чтение

Перед любой задачей прочитать:

1. [Project.md](Project.md) — продукт, состав репозитория и постоянные границы.
2. [Architecture.md](Architecture.md) — карта runtime, SDK и доставки контента.

Адресно по задаче:

- [Decisions.md](Decisions.md) — изменение архитектуры или контракта;

## Правила обновления

- Хранить только актуальные устойчивые факты и ссылки на первичные документы.
- Не копировать подробные правила, команды, логи или handoff целиком.
- Не хранить текущий прогресс, dirty paths, PID, lock owner и результаты одного
  запуска: это принадлежит `CoordinationRuntime/` и локальным инструментам.
- Изменение общего контракта обновляет первичный документ и memory-запись в
  одном scope; расхождение разрешается в пользу проверенного кода/конфига и
  фиксируется в handoff.
- Каждый файл держать короче 200 строк; историю переносить в `../archive/`.

Полный обязательный контракт определён в
[MemoryBankProtocol.md](../rules/MemoryBankProtocol.md).
