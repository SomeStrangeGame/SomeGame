# Каталог новелл

Этот проект собирает экран выбора новеллы. Это не самостоятельная игра: здесь
нет стартовой сцены и запуска приложения.

## Два редактируемых файла

- `Config/catalog.json` — список, порядок и доступность историй.
- `Assets/RemoteAssets/catalog/screen.prefab` — внешний вид каталога.

Чтобы добавить историю, добавьте в `catalog.json` запись с уникальным
`storyId`. Заголовок, описание и обложка загружаются из проекта этой истории.

В prefab объект `TEMPLATE - Story Card` является выключенным шаблоном карточки.
Приложение само создаёт из него видимые карточки. Не переносите prefab и не
переименовывайте его C#-компоненты: путь и компоненты являются контрактом.

## Проверка и сборка

```bash
Tools/novels-tools/novels-content validate catalog
Tools/novels-tools/novels-content build catalog editor
```

После сборки выберите `Novels → Catalog → Audit Built Content`. Целевой размер
bundle — 50 КиБ, предупреждение — 100 КиБ, ошибка — 500 КиБ.

Общая логика находится в `NovelsContentSdk`. Папки `Build`, `Library` и `Logs`
создаются автоматически и не редактируются вручную.
