# Последний кубик не спит

Атомарный content project детской интерактивной сказки `toybedtime`.
Исходный сценарий находится в `Assets/Ink`, три фоновые иллюстрации — в
`Assets/Locations`, карточка и обложка — в `Config`.

Проверка и сборка выполняются из корня общего репозитория:

```bash
Tools/novels-tools/novels-content validate toybedtime
Tools/novels-tools/novels-content build toybedtime editor
```
