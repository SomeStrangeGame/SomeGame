# Story-local presentation — «После последнего света»

## Художественный профиль

Диалоговая поверхность продолжает классическую сёдзё-аниме эстетику истории,
но не воспроизводит интерфейс или символику конкретного сериала. Основной
материал — полупрозрачное глубокое индиго с тонкой тёпло-золотой рамкой,
мягким внутренним свечением и редкими ромбовидными бликами. Лунные, планетарные,
тиарные и трансформационные знаки запрещены.

## Диалог

- Основной bubble располагается в нижней безопасной зоне и не перекрывает лица,
  кисти рук и край юбки Миры.
- Текст — тёплый почти белый; имя — янтарное для Миры, холодное мятное для Рена,
  нейтральное золотисто-серое для рассказчика.
- Минимальный контраст текста к подложке — 4.5:1.
- На светлом рассветном фоне opacity поверхности повышается; на тёмном аварийном
  фоне рамка приглушается, чтобы не конкурировать с красным светом сцены.
- Переход к следующей реплике обозначается маленьким световым лепестком без
  встроенного текста. Анимация медленная и отключаемая reduced-motion режимом.

## Выборы

- Выборы текстовые: смысл не зависит от иконки или цвета.
- Максимальная группа — три варианта. Каждая кнопка сохраняет удобную область
  касания и переносит длинную подпись максимум на три строки.
- Focus/pressed state усиливает золотую рамку без вспышки; disabled state не
  используется в текущей истории.
- Выбор согласия на прикосновение или поцелуй формулируется буквально и не
  маскируется романтическим символом.

## Персонажи и безопасная композиция

- Мира: left/center-left; Рен: right/center-right; eye-level framing.
- Допустимы `main`, `guarded`, `soft` для Миры и `main`, `tense`, `soft` для Рена.
- Никаких low-angle, upskirt, прозрачной одежды, кадрирования на груди или бёдрах.
- В сценах близости камера остаётся на уровне глаз; физический контакт следует
  только после соответствующего ответа Миры.

## State matrix для финальной проверки

1. Длинный narrator-текст на `rooftop-dawn` и `service-gallery-red`.
2. Длинная реплика Миры с обоими персонажами в кадре.
3. Три выбора границы в технической галерее, включая самую длинную подпись.
4. Pressed/focus states всех трёх кнопок.
5. Отсутствующий необязательный декоративный sprite: читаемый neutral fallback.
6. Узкий portrait viewport с safe area.
7. Сцена `installation-bloom`: максимальное свечение без потери контраста.

Реальный prefab, raster UI sprites и Player screenshots остаются частью
финального Unity validation-слота. Этот документ фиксирует authoring contract,
но не выдаёт статическую спецификацию за визуальную приёмку.
