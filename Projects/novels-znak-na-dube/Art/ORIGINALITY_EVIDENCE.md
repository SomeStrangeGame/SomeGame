# Originality evidence

Review dates: 2026-09-06 and extension review 2026-09-07. Scope: approved narrative package, complete extended `s01e01.ink`, five character packages, non-character art, cover and Bubble kit.

## Narrative and full text

Broad searches found several recent fantasy texts using forests that remember, names with magical weight, ancient trees, voices and footsteps. Closest surfaced examples included *The Silver Bough of Elarion*, *The Price of Forgotten Names*, *Before the Forest Spoke*, and the web chapter *The Old Path*. These are treated as collision evidence, not inspiration.

The first design pass therefore carried medium risk. The retained story was differentiated around a concrete configuration absent from the comparisons: villagers physically relocate boundaries by recasting a bronze bell into iron survey nails; stolen place-names function as coordinates; the blind bellkeeper acoustically distinguishes true memory from forest ordering; the mark is a debt-key; and three endings allocate responsibility rather than simply defeating or healing the forest.

Exact-phrase searches for «Тишина бывает щитом. Бывает крышкой», «Первый ключ повернулся» + «Сердечный дуб», «люди украли у леса границы» and «лес уже примеряет твой голос» produced no matching fiction text. Full prose, dialogue, scene transitions and ending sequence are independently authored for this project.

The 2026-09-07 extension adds three mandatory-route scenes rather than padding optional branches: a charcoal boundary where living roots preserve the family debt beneath ash; a drowned path shrine whose removable name tablets alter navigation; and a root archive where eight central vacancies connect erased places to Мирон’s trace. These additions reinforce the same causal system while introducing no borrowed proper nouns, quotations or recognizable scene sequence. The refreshed full-text review found no internal phrase borrowing or abrupt voice shift.

Result: **passed**, residual narrative/text risk low-to-medium because forest-memory and magical-name tropes are common. A future material rewrite must repeat the gate.

## Character packages

All five designs were generated from story-local briefs without artist names, franchise references or supplied third-party images. Review fingerprints:

- Яр: charcoal-worker soot, patched asymmetrical travel layers, forked-root palm debt-key; three identity-consistent states.
- Лада: copper dew jug, single copper braid ring, practical green over-trouser silhouette; three states from guide to injured survivor.
- Весна: burgundy council wool, braided gray crown, boundary-key belt; authority/fear pair.
- Тихон: square white beard, clouded eyes, patched charcoal coat and sparse bronze bells; neutral/listening pair.
- Мирон: wet russet work jacket, delayed root-shadow, youthful freckled face; memory/echo states.

No recognizable character or protected costume combination was identified during descriptive review. Identity consistency is good inside each generated sheet; remaining alpha edge and in-game scale judgment is deferred to the final visual slot. Each character result: **passed for production originality**, residual visual similarity risk low.

## Non-character art and UI

The environment package uses a project-specific combination of black-water trails, iron-pinned maps, free-standing bronze bell tower, pale motionless bird glade, underground village/root anatomy, a distributed Heart Oak network, an ash-covered charcoal boundary, a drowned path-name shrine and a root archive of suspended memory tablets. The root-eye mark remains a simple abstract motif and is never presented as an existing rune or logo. Prompts explicitly excluded named artists, franchises, logos and watermarks.

Generated sheets, including all three 2026-09-07 extension crops, were visually inspected for subject coverage, continuity and obvious embedded marks. No legible text, logo or watermark is visible. The cover and UI follow the same charcoal/pine/oxidized-bronze/bone-white palette. Result: **passed**, residual risk low; reverse-image tooling was unavailable, so descriptive comparison and human visual inspection are the recorded limitation.

## Provenance

Raster source sheets were produced with the built-in OpenAI image generation tool on 2026-09-06 from prompts recorded in `GENERATION_PROVENANCE.md`, then deterministically cropped into runtime files with macOS `sips`. No external artwork was copied. Audio is deterministic original synthesis from `Art/render_audio.py`; the only non-original binary is Liberation Sans, copied from the repository’s existing presentation dependency with its existing license/provenance.
